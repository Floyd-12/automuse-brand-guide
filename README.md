# AutoMuse｜汽车品牌与车型探索系统（增强版）

- 20+ 品牌介绍
- 40+ 代表车型卡片
- 品牌搜索、分类筛选与排序
- 车型搜索、类型筛选与排序
- 品牌详情、车型详情和品牌对比
- 响应式页面，支持手机和电脑

## GitHub Pages 部署
1. 创建 GitHub 仓库。
2. 上传此项目的全部文件到仓库根目录，确保 `index.html` 位于根目录。
3. Settings → Pages → Build and deployment 选择 `GitHub Actions`。
4. 在 Actions 页面等待 `Deploy to GitHub Pages` 成功。
5. 发布网址通常为 `https://你的用户名.github.io/仓库名/`。
